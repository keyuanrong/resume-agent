# 按搜索词控制查看数量与精简求职设置

## 目标

控制台让用户设置“每个搜索词查看数”，默认 20。每次点击开始后，每个搜索词独立累计实际打开的岗位；翻页或重复扫描同一搜索词仍计入同一额度。各词达到额度后结束本次扫描。

## 界面与配置

手动和 Agent 策略只展示同一个查看数。删除每日处理上限、城市、岗位类型、最低薪资和固定招呼语输入及摘要。新策略字段为 `jobsPerKeyword`，范围 1–1000，默认 20。旧策略中的 `dailyLimit`、`cities`、`jobType`、`minimumSalary`、`greeting` 不再影响运行，保存策略时移除。

## 执行

BOSS 脚本按搜索词累计查看数，达到额度后切换到未完成的搜索词；所有词完成后暂停。智联和前程无忧测试脚本也按当前搜索词单独计数。岗位历史去重继续生效，重复岗位不消耗额度。

BOSS 首次沟通继续使用平台自带的招呼语。智联若页面提供预填招呼语，可由用户确认后发送；若未提供预填内容，停在人工操作环节，不自行填入生成文本。

## 验证

后端测试确认新字段覆盖运行配置且旧字段失效；浏览器脚本测试确认搜索词独立计数、限额和换词；界面测试确认保存载荷没有已移除字段。保留测试模式和人工审核等原有发送控制。
