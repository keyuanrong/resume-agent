# Resume Agent

一个“本地控制台 + 招聘平台浏览器脚本”的求职辅助工具。用户可以使用纯手动规则，也可以让 Qwen Agent 分析简历、追问求职偏好并生成策略；两种模式最终都会转换成同一种策略，由平台执行层使用。

> Boss 直聘已跑通现有投递链路。智联招聘已跑通搜索、列表、详情、公司/JD 提取、评分和自动沟通，审核模式逐岗确认，自动模式在阈值、黑名单、去重和上限内直接沟通。智联网页端暂无已验证的回复列表和简历发送工具栏，因此不伪报“回复后已发简历”。前程无忧当前仅支持不发送的全链路测试。

## 已实现

- 本地 Web 控制台：`http://127.0.0.1:8000`
- Agent 开关，明确展示服务商、模型和密钥状态
- 免费本地模式：上传 PDF/DOCX/文本简历，在本机生成个人搜索词、技能词和完整评分词库，支持修改后确认
- 手动模式：也可以不上传简历，直接填写搜索词、技能、阈值、排除词、公司黑名单、招呼语和每日上限
- Agent 模式：上传 PDF/DOCX/文本/图片简历，分析画像，生成 5～8 个问题，生成并确认策略
- 阿里云百炼 Qwen 接入；API Key 单独保存在本机 `data/secrets.json`
- 规则优先、边界岗位调用 Agent 二次判断；Agent 失败时回退规则结果
- 三种投递模式：只筛选、审核后发送、自动发送
- 平台能力注册表：Boss、智联、前程无忧
- 简历资产与发送偏好：平台简历、回复后发送、PDF、图片
- 公司名称采集、黑名单拦截、跨次去重、运行日志和处理记录
- 公司名称是所有平台的必填安全字段；识别失败时强制转人工审核
- Boss 搜索、岗位评分、打招呼、收到新消息后选择平台已有简历

## 安全边界

- Agent 生成的策略必须由用户确认后才生效。
- 公司黑名单、每日上限等硬规则不会被 Agent 绕过。
- 默认模式是“审核后发送”，不会自动联系招聘者。
- 自动聊天默认关闭。
- API Key 和上传的简历都在 `data/` 下，该目录不会提交到 Git。
- 简历内容只有在用户主动点击“分析简历”时才发送给配置的模型服务商。
- PDF/图片直接发送取决于招聘平台页面能力。目前 Boss 自动链路仅验证了“平台已有简历”，不会把未完成的附件操作记成发送成功。

## 架构

```text
简历本地生成 ──┐
手动配置 ──────┼─> 统一求职策略（含个人词库） ─> 规则评分 ─> 边界岗位 Agent ─> 平台执行
Agent 生成 ────┘                                                    │
                                                       ├─ Boss（已接入）
                                                       ├─ 智联（已校准，单岗位确认沟通）
                                                       └─ 前程无忧（待校准）
```

主要文件：

- `main.py`：FastAPI 接口、统一策略、评分编排、日志和控制台入口
- `product_store.py`：本地产品配置、密钥和简历元数据
- `agent_service.py`：Qwen 简历分析、策略生成和边界岗位判断
- `local_strategy_service.py`：免费本地简历分析、岗位模板匹配和个人评分词库生成
- `resume_service.py`：简历保存与文本/图片读取
- `platforms.py`：平台能力和接入状态注册表
- `core.py`：现有规则评分逻辑
- `config.py`：旧配置兼容与底层评分参数
- `web_script.js`：Boss 直聘 Tampermonkey 执行器
- `static/`：产品控制台页面
- `user_config.example.json`：旧配置和底层运行参数模板
- `docs/ARCHITECTURE.md`：平台适配接口与扩展约定

## 快速开始

### 1. 安装依赖

建议使用 Python 3.10 或更高版本以及虚拟环境：

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Windows 激活虚拟环境：

```bat
.venv\Scripts\activate
```

### 2. 准备底层配置

```bash
cp user_config.example.json user_config.json
```

控制台确认策略后会覆盖搜索词、招呼语、阈值、公司黑名单和每日处理上限。`user_config.json` 仍负责浏览器等待时间、Boss 平台简历序号和底层评分参数等高级配置。

### 3. 启动服务

```bash
python main.py
```

然后打开：

```text
http://127.0.0.1:8000
```

### 4. 选择模式

免费本地模式：先在“简历资产”上传带可复制文字的 PDF、DOCX、TXT 或 Markdown，在手动规则页选择简历并点击“本地分析并生成”。系统会列出多个候选职业方向，用户必须选择自己真正想投递的方向，再生成该方向的词库。系统不会调用 Agent，也不会把简历上传到第三方。检查搜索词、技能词、排除词以及“评分词库”高级项后，点击“保存并启用手动策略”。

纯手动模式：不上传简历也可以直接填写关键词、技能、阈值、排除项、公司黑名单和招呼语。保存时系统会根据这些内容构造个人评分词库，不再使用仓库里的固定 VLA 词库。

Agent 模式：

1. 开启 Agent。
2. 填写阿里云百炼 API Key 和模型名。
3. 上传并选择一份简历。
4. 点击“开始分析”。
5. 回答 Agent 提出的补充问题。
6. 生成最终策略并确认。

默认模型名是 `qwen3.8-flash`，也可以在页面中修改为你的百炼账号实际可用的兼容模型名。

### 5. 安装 Boss 浏览器脚本

把 `web_script.js` 的内容粘贴到 Tampermonkey，新建并保存脚本。保持本地后端运行，然后登录并打开 Boss 直聘岗位页。

### 6. 测试智联和前程无忧完整链路

把 `multi_platform_test.user.js` 作为一个独立脚本安装到 Tampermonkey。智联和前程无忧现在使用与 Boss 相同的左下角控制面板和操作方式，包含“清空、开始/暂停/继续、收起/展开”，并读取同一份多关键词策略、每日处理上限和筛选条件。它会测试登录识别、搜索、筛选状态、列表滚动、岗位详情、公司和 JD 提取、去重、规则/Agent 评分、简历与联系动作计划和运行日志。

测试两个平台时，在本地控制台把“运行环境”设为“测试模式”。测试模式会强制校验 `allowExecute=false`，不会执行沟通、申请、简历发送或自动回复。

智联单岗位沟通试运行时，先将“运行环境”设为“正式模式”并启用智联平台。脚本只会在第一个达标岗位上弹出确认；用户确认后才会点击“立即沟通/申请职位”。如果出现聊天输入框，系统填入招呼语后还会再次询问是否发送。无论成功、失败还是取消，都会立即停止，不会继续处理下一个岗位。

登录智联或前程无忧并进入岗位列表页，点击左下角“开始”。脚本会像 Boss 一样轮换已保存的搜索关键词，并在达到每日处理上限或全部关键词完成后停止。第一次运行主要用于校准两个网站登录后的真实 DOM；任何失败都会显示具体阶段，并写入 `/job-report`。

## 投递模式

- `只筛选`：评分和记录岗位，不自动打招呼。
- `审核后发送`：合格岗位进入“等待审核”，不自动打招呼。
- `自动发送`：合格岗位自动打招呼，并启用已有的 Boss 新消息检测/平台简历发送流程。

第一轮使用建议选择“审核后发送”，先观察处理记录和评分结果，再决定是否启用自动发送。

“运行环境”与“投递方式”是两层独立安全控制：测试环境永远不会执行发送；正式环境也只有已完成正式适配、策略为自动发送且所有硬规则通过的平台才可能执行动作。

## Agent 的职责

Agent 只负责：

- 从简历提取候选人画像。
- 提出少量求职偏好问题。
- 生成搜索词、排除项、阈值和招呼语。
- 对规则分数处于边界区间的岗位做二次判断。

Agent 不负责：

- 登录招聘平台。
- 绕过平台限制或用户硬规则。
- 直接操作简历上传控件。
- 未经确认修改账号或自动回复招聘者。

## 平台扩展

`GET /api/platforms` 会返回每个平台的接入状态和能力，例如是否支持搜索、公司名、首次附件、PDF、图片和平台简历。

增加平台时，应按 [平台适配设计](docs/ARCHITECTURE.md) 实现同一组动作，再对真实登录页面进行人工校准与小流量验证。页面变化可能导致浏览器自动化失效，因此平台不能仅凭接口占位就标记为“已接入”。

## 本地数据与 Git

以下内容默认不会提交到仓库：

- `data/`：Agent 配置、API Key、上传的简历
- `user_config.json`：个人运行配置
- `job_decisions.jsonl`、`job_actions.jsonl`：执行记录
- 个人简历文件

公开仓库里只保留示例配置。提交代码前可用 `git status` 确认没有隐私文件进入暂存区。

## 当前限制

- 智联招聘已完成真实列表/详情页校准，正式模式只开放单岗位人工确认沟通；前程无忧仍只开放不发送的测试链路。两者的附件发送都未开放。
- Boss 的 PDF/图片附件发送尚未完成可靠校准；当前可自动选择招聘平台已有简历。
- 页面自动化依赖招聘网站 DOM，网站更新后可能需要调整选择器。
- 免费本地模式不包含 OCR；扫描版 PDF 和图片简历请改用可复制文字的文件，或者在明确同意数据发送后使用 Agent 模式。
- 本地岗位模板当前覆盖销售、市场运营、客服售后、人力行政、财务会计、VLA/具身智能、AI应用、后端、前端、数据、机器学习、DevOps、产品、嵌入式和机械自动化；无法识别时会要求用户手动填写，不会假装生成可靠策略。
- 使用招聘平台自动化前，请自行确认并遵守对应平台条款、频率限制和适用规则。
